## 겪은 문제와 해결

### OMY
| 문제 | 원인 | 해결 |
|---|---|---|
| SSH: TCP 22는 연결되는데 `Connection timed out during banner exchange` | USB 랜 허브 (재부팅·USB-A 직결로는 안 풀림) | **더 좋은 허브로 교체**하니 해결 |
| bringup `0xc Multi-turn Error` | 액추에이터 멀티턴 상태 이상 | Debug USB + Dynamixel Wizard 2.0 (ROBOTIS 방법 2). 계획서 **부록 A** |
| Wizard Packet 창이 포트를 못 엶 | 메인 창이 `/dev/ttyACM0` 점유 | 메인 창 **Disconnect** 후 Packet 창에서 Open → Clear |
| 토크가 안 켜짐 | 알람이 걸린 다이나미셀은 Torque Enable 거부 | 먼저 Clear |
| Clear 후 원점이 틀어짐 | 홈이 아닌 자세에서 Clear | 6축을 홈 슬릿에 맞춘 뒤 ID 1~6에 다시 Clear, ±1° 확인 |
| `zenohd: command not found` | 컨테이너 `.bashrc`가 로드되지 않은 셸 | `ros2 run rmw_zenoh_cpp rmw_zenohd` |
| 팔은 움직이는데 LEAP 무반응 | 같은 셸에서 `omy_ai`가 `RMW_IMPLEMENTATION`·`ROS_DOMAIN_ID` 없이 실행 → zenoh 미연결, PC에서 발행자 0개 | `export ROS_DOMAIN_ID=30 RMW_IMPLEMENTATION=rmw_zenoh_cpp` 후 재실행 |
| leader 로그 `BULK_READ_FAIL` (-3001/-3002) 반복 | leader 버스(모터 7개) 간헐적 통신 실패 | 10ms/500ms 허용 안이라 동작은 계속됨. 원인 미조사 |
| **텔레옵 중 leader가 갑자기 크게 튐** | 미확인 (위 통신 실패와 관련 있는지 모름) | 텔레옵 중에는 **leader를 반드시 손으로 잡는다** |

### LEAP Hand / User PC
| 문제 | 원인 | 해결 |
|---|---|---|
| `ModuleNotFoundError: dynamixel_sdk` | `ros-jazzy-dynamixel-sdk`는 ROS source 후에만 import 됨 | ROS source 한 `python3` 또는 `.venv/bin/python` (README 수정) |
| `--output: expected one argument` | 붙여 넣을 때 명령 줄이 잘림 | 한 줄로 실행 |
| 엄지 CMC(ID 13) 영점이 629° | XC330 모드 5의 회전수 누적 | 손을 편 채 5V 재투입 후 재기록 → 269°. 이후 다시 잡아 최종 약 180° |
| 주먹이 덜 쥐어짐 | 보수적 시험값(55/60/40) | 완전히 쥐는 값으로 변경 (`d384e11`, 출처 `leap-hand@ddfabaa` `neutral_calibration.py`) |
| 팔이 움직일 때 손이 펴질 수 있음 | 입력이 없을 때(`waiting`/`release`) 편 손으로 감 | `--safe-pose fist` 추가 (`185ef00`) |
| `--safe-pose` 인식 안 됨 | 코드 반영 전 실행 | 브랜치 갱신 후 해결 |
| 엄지가 잘 안 닫힘 | 엄지 뒷부분을 받쳐 주는 기구가 없음 | **미해결 (하드웨어)** |

## 성공한 실행 순서 (5-b)
1. Robot PC A: `zenohd` (또는 `ros2 run rmw_zenoh_cpp rmw_zenohd`, 셸에 `ROS_DOMAIN_ID=30`, `RMW_IMPLEMENTATION=rmw_zenoh_cpp`)
2. User PC: `python3 -m leap_teleop.cli --source leader --safe-pose fist` → 주먹, `[teleop] waiting`
   (`source /opt/ros/jazzy/setup.bash`, `ROS_DOMAIN_ID=30`, `RMW_IMPLEMENTATION=rmw_zenoh_cpp`,
   `ZENOH_CONFIG_OVERRIDE='mode="client";connect/endpoints=["tcp/10.42.0.241:7447"]'`, `PYTHONPATH="src:$PYTHONPATH"`)
3. Robot PC B: `omy_ai` (leader 그리퍼를 쥔 채로) → `[teleop] live`
4. 종료: B `Ctrl+C` → User PC `Ctrl+C` → A `Ctrl+C`

## 측정값
- LEAP 영점 (`config/hardware_motors.yaml`, gitignore됨): 16개 모두 0~360° 안, sign 모두 +1.
  MCP flex(ID 1·5·9)는 약 82~89°로 다른 관절(약 165~188°)과 90° 정도 다르다. Homing Offset 0 확인, 혼 조립 방향 차이로 보이며 영점 파일이 흡수한다.
- leader `rh_r1_joint` 편 상태 ≈ 0.197 (토픽에는 offset 0.2가 이미 적용).
