준비

안전 수칙 (매 단계)

  • LEAP 5V를 즉시 끊을 수단을 손 닿는 곳에 둔다. 이상하면 5V를 먼저 끊고 Ctrl+C.
  • 5V는 항상 손을 편 상태에서 켠다. 모터가 회전수를 누적해서, 접힌 채 켜면 다음 전원 투입 때 영점이 360° 어긋난다.
  • 시험 중 손가락 주변에 손·케이블을 두지 않는다. LEAP Hand v1(16모터) 전용이다.
  • omy_ai는 launch 즉시 팔이 움직인다. 작업 공간을 비우고 비상 정지 수단을 확인한다.
  • 팔이 움직이는 동안 손은 주먹으로 둔다. (leap_* 함수는 --safe-pose fist가 기본)
  • 텔레옵 중에는 leader를 반드시 손으로 잡는다. 10/09에 leader가 갑자기 크게 튄 적이 있다.
처음 구동은 항상 --dry-run 먼저, 그다음 leap_manus (엄지 IK, 기본)로 간다. --thumb affine은 손가락·엄지 대응이 의심될 때 진단용으로만 쓴다. 실측 11/03 IK가 더 좋았다.

leader 트리거로 LEAP 열고 닫기

오늘은 환경 확인용이다. 팔 + zenoh + LEAP 경로가 살아 있는지 본 뒤 3단계로 간다.

leader 트리거 값 입력 (쥔 상태는 아직 미측정)

편 상태와 쥔 상태에서 7번째 값을 읽어 user_pc/config/leader_gripper.yaml의 open_value / closed_value에 넣는다. 지금은 임시값 0.0 / 1.0이고, 편 상태 실측은 약 0.197이다.

USER PC 
leap_leader --dry-run     # 먼저 로그만. 트리거를 쥐고 펼 때 값이 따라가는지
leap_leader               # 실물. 주먹 → [teleop] waiting → live
토픽이 0.5초 끊기면 마지막 자세를 유지(hold), 3초 끊기면 안전 자세(release). Ctrl+C로 종료하면 Torque OFF.
전환

2단계 정리, 3단계 준비

3단계(Manus 단독)는 팔이 필요 없다. 아래 순서로 끄고 새로 시작한다.

  1. User PC: leap_leader 셸에서 Ctrl+C (Torque OFF).
  2. Robot PC 터미널 B: omy_ai Ctrl+C — 팔이 처질 수 있으니 손으로 받친다.
  3. Robot PC 터미널 A: zenohd Ctrl+C.
  4. LEAP 5V를 편 손으로 껐다 켠다 (모터 회전수 누적 초기화).
3단계 셸은 모두 LEAP_NO_ZENOH=1이어야 한다 (~/.bashrc 기본값). 2단계에서 unset 했던 셸이면 export LEAP_NO_ZENOH=1 후 leap_env를 다시 한다. 확인: echo "[$RMW_IMPLEMENTATION]"이 [].
단계 3 · Manus 단독 (팔 없음)

Manus 노드 실행과 확인

코드가 SDK 소스에서 읽어 가정한 값이 맞는지 실제 echo로 확인한다. 글러브를 착용한다. 실측 11/03 아래 항목 모두 확인됨.

셸 1 · Manus 노드 (이 User PC, 동글도 이 PC에)
MANUS Core Dashboard를 먼저 끈다. 노드는 integrated 모드(기본)로 동글을 직접 연다. Dashboard가 켜져 있으면 Resource busy + No license found … Integrated로 토픽이 안 나온다. 확인: pgrep -a MANUS_Core가 비어 있어야 한다. Dashboard에 붙는 local 모드(-p connection_type:=local)도 넣어 두었지만 Linux Dashboard는 SDK 연결을 받지 않아 쓸 수 없었다.
leap_env
echo "[$RMW_IMPLEMENTATION]"                    # [] 이어야 한다
ros2 run manus_ros2 manus_data_publisher        # "running in integrated mode", Resource busy 없음
셸 2 · 확인 
leap_env
ros2 topic list | grep -i manus                 # /manus_glove_0, /manus_glove_0/vibration_cmd
ros2 topic hz /manus_glove_0                    # 약 120 Hz (11/03: 119.9)
ros2 topic echo /manus_glove_0 --once > ~/echo.txt

echo.txt에서 확인한다. 하나라도 틀리면 키포인트가 빠져 엄지가 조용히 affine으로 돈다.

토픽이 /manus_glove_0이 아니면 user_pc/config/manus_leap.yaml의 topic을 바꾼다. 왼손이면 --glove-side Left. 오른손을 /manus_glove_right로 고정하려면 노드를 -p glove_topic_template:=manus_glove_{side}로 실행한다.
노드는 120 Hz로 마지막 값을 반복 발행하고 timestamp가 없다. ergonomics가 0.5초 넘게 완전히 같으면 끊김으로 보고 hold한다.

dry-run (LEAP을 건드리지 않음)

USER PC

waiting에서 안 바뀌면 순서대로:
  1. 노드가 도는가, ros2 topic echo로 값이 오는가

엄지 방식 (11/03 수정)

관절방식설정
12·13·14번IK: 엄지 끝 + IP 관절 위치를 맞춘다thumb_ik.ip_weight: 0.3
15번 (엄지 맨 위 관절)글러브 ThumbIPStretch를 그대로 따른다 (affine). 끝만 맞추는 IK에서는 15번이 거의 안 굽었다 실측 11/03thumb_ik.ip_joint: affine (예전 방식은 ik)
15번 젖힘편 손보다 더 젖히면 LEAP도 뒤로 젖힌다 (최대 20°). 전에는 0°에서 잘렸다 미검증thumb_ip_extend_max_deg: 20.0 (0 = 끔)

안 맞을 때

  • 손가락 방향이 반대 → manus_leap.yaml의 side_gain 또는 joint_map
  • 엄지가 이상함 → --thumb affine으로 대응표부터 맞춘 뒤 IK
  • 엄지 맨 위 관절이 덜/더 젖혀짐 → thumb_ip_extend_max_deg
  • pinch 틈이 큼 → 15번 고정 때문일 수 있다. ip_joint: ik와 비교
  • 검지가 끊김 실측 11/03: 글러브 IndexPIPStretch가 MCP가 굽는 동안에도 0~1°에 붙어 있는 구간이 있었다 (수신은 120 Hz로 정상). 장갑을 다시 끼고 센서 위치를 확인, 그래도면 Dashboard에서 글러브 캘리브레이션 후 Dashboard를 끄고 노드 재실행. 계속되면 PIP=0이고 MCP가 굽었을 때 MCP 비율을 빌리는 보정을 검토 미검증
  • IK에서 손끝 틈이 남음 → pinch snap 추가 검토 (spec 7절)
  • pinch 결과는 docs/field-test/에 10/09 형식으로 남긴다
단계 4 · Manus + 팔

Manus + 팔

팔은 leader, 손은 글러브. 두 프로세스는 독립이고 leader 트리거는 LEAP에 영향이 없다 (--source manus).

  1. 3단계를 끝낸 뒤 leap_manus를 Ctrl+C로 종료하고, LEAP을 주먹으로 대기시킨다 (safe-pose가 주먹).
  2. ROBOT PC 터미널 A zenohd, 터미널 B omy_ai (앞의 “zenohd와 omy_ai” 단계). leader 트리거를 쥔 채로.
  3. Manus 노드(셸 1)는 그대로 두고:
USER PC 
export LEAP_NO_ZENOH=1
leap_manus
leader를 손으로 잡고 한다. 팔이 움직이는 동안 LEAP은 주먹이어야 한다.

종료 순서

  1. 녹화가 끝났는지 확인한다.
  2. leap_* 셸 Ctrl+C (Torque OFF). 손이 풀려 처지니 물체가 손에 없는지 본다.
  3. 카메라 터미널들, Cyclo 터미널.
  4. omy_ai Ctrl+C — 팔이 처질 수 있으니 손으로 받친다.
  5. zenohd Ctrl+C, Manus 노드 종료.
  6. LEAP 5V OFF.
  7. 보관하려면 다음 단계의 pack, 그다음 로봇 전원 OFF.
켜는 순서: LEAP 5V(편 손) → Manus 노드 → zenohd → omy_ai → leap_* → Cyclo 녹화. 끄는 순서는 반대.

pack / unpack

OMY를 접어 보관하거나 펴는 launch다. omy_3m.launch.py에 목표 자세만 바꿔 넣는 래퍼다.

명령이동자세
packros2 launch open_manipulator_bringup omy_3m_pack.launch.pyhome → pack (각 10초)[0, 0, −150°, −30°, 0, 0]
unpackros2 launch open_manipulator_bringup omy_3m_unpack.launch.pyhome전부 0
  • omy_ai와 동시에 실행하지 않는다 (둘 다 follower ros2_control을 띄운다).
  • omy_3m은 끝단 없는 6축 모델이다. LEAP을 단 채로 접을 때 손이 베이스·바닥에 부딪히는지는 확인된 바 없다. 미검증 처음에는 손을 떼거나, 팔을 받치고 5V를 끈 채 천천히 한다.
  • 접기 전 LEAP 5V를 끄고 케이블이 당기지 않는지 본다.
최초 수령 시 포장 해제(unpacking) 절차는 이 레포에 없다. ROBOTIS Setup Guide를 따른다: docs.robotis.com … setup_guide
