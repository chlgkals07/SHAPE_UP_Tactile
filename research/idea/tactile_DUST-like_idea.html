01

아이디어와 핵심 가설

초기 제안부터 현재 가장 설득력 있는 연구 질문까지

현재의 중심 연구 질문

기존 VLA의 action expert에 action step과 정렬된 tactile prediction을 결합하면, chunk 내부의 접촉 dynamics를 더 잘 학습하여 dexterous manipulation 성능을 개선할 수 있는가?

초기 동기

Action chunk를 한 번에 생성하면, 실행 중 tactile 상태가 바뀌어도 이미 정한 action에 그 변화가 반영되지 않을 수 있다. 특히 짧은 접촉 시작·해제, 미끄러짐 전조, 힘의 급증, 손가락 간 하중 이동은 조작 결과에 중요할 수 있다. 사용자는 이 문제에 future prediction / world modeling의 학습 이득을 적용하고자 했다.

초기 구성은 π0.5·GR00T 같은 VLA 또는 FTP-1 같은 tactile policy의 action 생성 경로 옆에 미래 tactile latent 생성 stream을 추가하는 것이다. 구현 출발점으로 DUST의 dual-stream 구성을 고려했다. Tactile-VLA·FTP-1은 tactile policy 배경, TacForcing은 실행 중 tactile 갱신과 관련된 연구다.[3][4][5]

입력·플랫폼 후보

기존 VLA + array force sensor

Vision, language, proprioception, 현재 tactile 및 필요한 history를 입력으로 사용한다. PaXini 계열 등 array sensor를 dexterous hand에 적용하는 방향이다.

센서 모델, taxel 수, force 축, 측정 주기, 지연, hand의 action 표현은 아직 확정하지 않았다. 특정 장비의 성능 수치를 가정하지 않는다.

예측 대상

Action chunk + future tactile latents

Action과 tactile은 서로 다른 encoder·projection·expert를 사용할 수 있다. 현재 vision은 conditioning으로 유지하되, 미래 video 생성은 초기 구현의 필수 요소로 두지 않는다.

손가락별 구조와 taxel의 공간 정보는 보존할 후보이다. 구체적인 압축 방식과 token 수는 실험으로 결정한다.

아직 입증되지 않은 연결

High-frequency tactile → 반드시 1:1 예측이 최적이라는 결론은 아직 없다. 예를 들어 30 Hz action과 맞추어도 33 ms보다 짧은 이벤트는 놓칠 수 있다. 반대로 안정적인 접촉에서는 성긴 예측으로 충분할 수 있다. 실제 접촉 변화의 시간척도를 측정해야 한다.

또한 dense prediction은 실행 중 feedback 갱신을 대신하지 않는다. 예상 가능한 접촉 변화에 대한 선제적 제어와 예측 밖 교란에 대한 반응을 별도로 검증한다.

대화에서 구체화된 방향

미래 tactile stream 추가→Array sensor · dexterous 설정→Dense alignment · mask 검토→VLA 개선을 중심 기여로 설정
02

타당성 · 독창성 평가

Top-tier ML conference에서 설명해야 할 주장과 증거

현재 평가 실험할 가치가 있는 방향이다. 다만 현재는 방법과 결과가 확정되지 않은 단계다. 좋은 결과가 나온다는 가정 아래 논문으로 발전시킬 수 있는 논리를 평가한 것이며, acceptance 가능성이나 성능을 수치로 예측하지 않는다.

평가 축현재 판단논문에서 필요한 증거
문제의 중요성설득력 있는 문제 후보접촉 변화가 chunk 내부에서 발생하고, 기존 tactile-input VLA가 이를 충분히 활용하지 못한다는 데이터·실패 분석.
기술적 타당성구현 가능한 조합현재 context로 미래 tactile을 예측하고 action과 공동 학습할 수 있는지, timestamp 정렬과 train–test conditioning이 맞는지 확인.
독창성기본 stream 추가만으로는 제한적DUST의 tactile 확장 대비 dense alignment 또는 interaction 구조가 해결하는 새로운 문제가 무엇인지 명시.
방법론적 기여효과의 분리가 필요예측 target의 밀도, stream 분리, mask, 추가 supervision·parameter의 효과를 각각 검증.
실험적 엄밀성아직 평가 불가같은 backbone·데이터·입력·실행 주기, 반복 학습·robot trials, 불확실성 구간, 실패를 포함한 평가.
일반성·실용성검증할 가치가 큼물체·마찰·강성·접촉 구성 변화, 데이터 효율, 실제 latency와 메모리, pretrained policy 능력의 유지.

서로 다른 수준의 주장을 구분한다

기본적으로 입증할 주장

같은 tactile 입력을 받는 기존 VLA보다, 미래 tactile 예측을 결합한 VLA가 접촉 제어를 더 잘한다.

더 강한 방법론적 주장

동일한 dense target을 사용해도, 제안한 stream 또는 mask가 auxiliary head·기본 공동 출력·full attention보다 낫다.

결과가 있을 때 확장할 주장

Dense prediction의 이득이 접촉 전환이 잦은 조작에서 커지고, 동일 계산 예산에서 다른 모델보다 우수하다.

현재 확정할 수 없는 주장

“최초”, “항상 1:1이 최적”, “모든 WAM보다 우수”, “dexterous에서 항상 더 유리”는 아직 뒷받침되지 않았다.

성공률 상승만으로 설명되지 않는 것

예측 loss 감소는 policy 개선과 같지 않다. Action이 더 좋아져도 그 원인이 추가 parameter, 늘어난 supervision, pretrained action prior일 수 있다. 예측 정확도 → 예측 특징의 실제 활용 → 제어 개선을 연결하는 ablation이 필요하다.

반대로 모든 아이디어를 동시에 입증할 필요도 없다. Dense prediction만 일관되게 유효하고 제안 mask의 추가 이득이 없다면, mask를 핵심 기여로 내세우지 않고 검증된 결과에 맞춰 논문 범위를 정한다.

03

포지셔닝 · 관련 연구

VLA augmentation을 중심에 두고, 기술적 중복은 정확히 인정한다

현재의 포지셔닝: tactile world modeling으로 기존 VLA의 action generation을 개선한다. 모든 tactile WAM의 기능을 능가하는 것을 출발 조건으로 삼지 않는다. 가장 직접적인 질문은 “DUST를 tactile로 확장한 기본 모델보다 무엇을 더 해결하는가?”이다.

DUST 확인 DUST는 ICML 2026 proceedings에 게재되어 있다. Related works의 “largely orthogonal”은 Cosmos Policy·Fast-WAM·DreamZero처럼 video-generation prior에서 policy를 만드는 계열과, VLA에 world-modeling objective를 결합하는 자신의 출발점을 구분하는 문맥이다. Acceptance만으로 학회가 연구 분류 자체를 공식 판정했다고 해석할 수는 없다.[1]

대화 초반에는 tactile WAM과의 중복을 강하게 검토했지만, 후반에는 같은 VLA 안에서의 통제된 비교를 주된 증거로 삼는 방향으로 정리했다. WAM과 공유하는 기법의 선행성은 인정하면서, 비교 실험의 우선순위는 연구 주장에 맞춘다.

연구이 논의와 관련된 핵심우리 연구에서의 역할
DUST[1]VLA에 action·future observation embedding의 dual stream, 독립 noise, 공동 생성 학습을 결합.가장 직접적인 방법론 출발점. Tactile로 기본 확장한 모델과 비교.
FLARE[2]정책 내부 특징을 미래 observation representation과 정렬하는 implicit world modeling.예측 학습만 추가하는 경량 접근과 비교할 근거.
Tactile-VLA / FTP-1[3][4]VLA에 tactile sensing을 통합하는 배경. FTP-1은 서로 다른 tactile sensor를 다루는 foundation policy.현재 tactile conditioning과 predictive augmentation의 효과를 구분.
TacForcing[5]실행과 fresh tactile 관측을 번갈아 반영하며 action을 점진적으로 생성.실행 중 feedback 문제를 해결하는 관련 축. Dense 예측과 반응성을 혼동하지 않기.
Dream-Tac[6]공유 DiT에서 action·vision·tactile을 양방향으로 결합하고 contact-aware attention bias 사용.공동 생성·양방향 attention 자체의 선행성. Endpoint 대비 trajectory 효과 검토.
TacPAC[7]예측된 tactile/action 특징을 cache하고, 실행 중 현재 tactile로 미실행 action을 보정.Sub-idea인 prediction-grounded real-time correction의 직접 관련 연구.
DexTacWAM[8]다지 tactile을 finger·pose-aware하게 압축하고 world-model 특징을 action expert에 제공.Dexterous 적용·다지 표현 자체는 차별점으로 충분하지 않음. Force target baseline도 필요.
ViTaL[9]Visual 후보 선택과 짧은 tactile-guided diffusion editing을 분리한 inference-time steering.Gradient steering을 설계할 때 참고. 세부 원리는 07절.
VT-WAM[10]현재 visual anchor와 tactile sequence를 action이 읽는 비대칭 attention. 추론 시 미래 visual token 제거.미래 video를 생략한 tactile 중심 생성에도 선행연구가 있음.
N₀-TWAM[11]Video·tactile·action 전문가와 frame-id 기반 predict-then-act cascade.별도 tactile expert 및 causal mask 자체의 novelty를 과장하지 않기.
Tactile-WAM[12]Visual stream의 tactile 접근을 제한하고 action의 tactile attention을 조절.Attention 설계에 대한 추가 관련 연구.
DexTouch-WM[13]공유 sensing layout의 piezoresistive array와 action-conditioned tactile world modeling.“Array sensor + dexterous” 조합만으로 최초성을 주장하기 어렵다는 배경.

관련 연구 목록은 대화에서 다룬 문헌과 이를 확인하는 과정에서 필요한 문헌을 정리한 것이다. 전체 분야의 exhaustive survey나 모든 논문의 학회 게재 상태 검증을 의미하지 않는다.

Array sensor와 dexterous hand에서 주장할 수 있는 장점

직접적인 force 표현, taxel 위치, 손가락 간 하중 분포는 접촉 dynamics를 학습하기 좋은 기반이 될 수 있다. 그러나 sensor가 바뀌었다는 사실만으로 algorithmic novelty가 생기지는 않는다. 손 전체의 총힘이 비슷해도 국소 접촉 분포가 다른 상황에서 제안 표현이 왜 필요한지 보여주는 편이 강하다.

영상 기반 tactile sensor에도 풍부한 접촉·변형 정보가 있다. Array sensor가 항상 더 빠르거나 더 저렴하거나 더 정확하다는 전제는 두지 않는다. 실제 장비의 대역폭·노이즈·포화·지연을 확인한다.

Modality 수준의 attention 방향

아래의 “읽는다”는 행의 modality가 Query이고 해당 modality의 Key/Value에 접근한다는 뜻이다. 언어·현재 관측 conditioning과 세부 layer 배치는 생략했다.

모델Action queryVision queryTactile query
TacPAC base[7]A, V, TV, TV, T
Dream-Tac[6]A, V, TA, V, TA, V, T
DexTacWAM[8][C3]A self-attention + V·T cross-attentionV, TV, T

TacPAC의 별도 tactile expert는 미래 tactile 생성 stream이 아니라 action correction 모듈이다. Dream-Tac의 CASA는 비촉각 query→tactile key에 bias를 더한다. DexTacWAM의 공개 구현은 매 세 번째 block에서 cross-view attention을 사용한다. Attention 경로와 loss의 gradient 경로는 별개이다.

추가 확인: denoising 횟수와 실제 시간 간격은 다르다

TacPAC은 10 flow steps 후 clean cache pass를 추가한다. Dream-Tac의 공개 cache 경로는 5 sampler steps 중 DiT block 전체를 2회 계산하므로 단순한 “2-step sampler”가 아니다. DexTacWAM의 action-only pipeline은 world-model 특징을 한 번 계산해 반복적인 action denoising에서 재사용한다. 이 차이를 비용 비교에 반영한다.[7][C4][C5]

우리 모델의 interleaving: 순서보다 연결 규칙이 중요하다

시간·modality embedding과 mask를 동일하게 대응시키면, token의 단순 저장 순서는 본질적 차이가 아닐 수 있다. Dual stream의 private weights와 shared attention을 유지하면서, action과 그 결과인 tactile을 어떤 범위로 연결할지를 결정해야 한다.

설계 후보 · 실험 결과 아님

세 가지 attention mask 비교

행 = Query · 열 = 읽을 수 있는 Key/Value. T는 예측할 tactile latent이다. 현재 관측 context는 별도 conditioning으로 생략했다.

접근 허용같은 transition의 A↔T차단

전체 양방향 attention

모든 action과 tactile token이 서로 접근한다. 생성 중인 전체 trajectory를 함께 조정하는 기준 모델이다.

미래 예측 token은 생성 중인 가상 미래이다. 실제 미래 정답을 inference 조건으로 사용하는 것은 허용되지 않는다.

대각선은 자기 자신의 noisy token을 읽는 denoiser 구성을 뜻한다. Clean 정답 자기 참조를 허용한다는 의미가 아니다. 이 mask만으로 물리적 인과성이나 특정 확률 분해가 보장되는 것은 아니다.

엄격한 causal mask의 제한: at 뒤에 Tt+1을 배치하면 at가 자신이 만들 접촉 예측을 직접 읽지 못한다. 예측 학습의 간접적인 이득은 가능하지만, 미래 접촉을 보고 그 action을 조정하려는 의도와 다를 수 있다.

권장 출발점: Dense dual stream의 full attention을 먼저 구현하고, 같은 (ai, Ti+1) block 내부는 양방향으로 유지하면서 block 사이에 시간 제약을 추가한 구성을 비교한다. 엄격한 forward dynamics가 필요하다면 encoder, action self-attention 등을 통한 간접 정보 경로까지 점검한다.

Interleaving은 token별 순차 생성을 강제하지 않는다. 전체 chunk를 각 denoising step에서 병렬 처리할 수 있지만, mask·noising·sampling은 함께 설계해야 한다. Diffusion Forcing은 독립적인 token별 noise를 사용하는 관련 기반이다.[14]

Dual stream ≠ 자동으로 저비용. 전체 token을 full attention으로 연결하면 attention 항의 O(N²) 비용은 남는다. Dense tensor 계산 후 mask만 적용하는 구현도 같은 문제가 있다. 공간 token 압축, 작은 expert, context 재사용, 실제 sparse/block 연산이 비용 절감의 원인이어야 한다.

05

질문별 논의 정리

사용자가 제기한 질문과 현재까지의 답변

Q01초기 아이디어는 타당하고, 실험할 가치가 있는가?

예측 학습을 통해 접촉 dynamics를 action 생성에 활용하려는 방향은 타당하다. 현재 가장 중요한 검증은 동일한 tactile-input VLA에서 예측 학습이 추가적인 이득을 주는지다. 구현 가능성과 논문 novelty는 별도 문제이며, 후자는 기존 방식 대비 구체적인 차이와 실험 결과가 필요하다.

Q02VLA의 dual stream도 결국 tactile WAM과 같은 아이디어인가?

미래 tactile과 action을 함께 학습한다는 기술적 공통점은 있다. 그러나 pretrained VLA를 개선하는 출발점과 video model에서 policy를 만드는 출발점은 구별할 수 있다. 연구의 중심을 VLA augmentation으로 두되, 같은 기술을 먼저 사용한 연구는 관련 연구로 인정한다.

Q03Array sensor와 dexterous hand 적용만으로 차별성이 생기는가?

적용상의 차이는 있지만 그것만으로 강한 방법론적 novelty를 보장하지 않는다. Force 단위와 taxel 위치, 다지 하중 이동을 활용하는 표현이 왜 필요한지 보여야 한다. 같은 총힘으로 구분되지 않는 접촉 분포나 regrasp에서의 이득이 좋은 검증 대상이다.

Q04ViTaL은 어떻게 action을 steering하는가?

먼저 visual 결과로 action 후보의 행동 방향을 선택한다. 선택된 action을 부분적으로 re-noise한 뒤, action-conditioned world model의 tactile 예측에 text-conditioned reward를 적용해 짧은 구간을 diffusion editing한다. 예측–실측 오차를 센서 주기마다 보정하는 방식과는 목적함수가 다르다. 07절의 원리 요약 참고.

Q05기존 WAM의 action·video·tactile horizon과 step size는 같은가?

같은 미래 구간을 다룰 수 있어도 sample 수와 간격은 다르다. 공개 설정에서 Dream-Tac은 endpoint, TacPAC은 4 action steps 간격, DexTacWAM 영상 경로는 6 steps 간격이다. DexTacWAM의 별도 force target과 VAE 시간 압축도 구분해야 한다. 04절 비교표 참고.

Q06Dense하게 1:1 정렬하고 interleaved attention을 쓰면 어떤가?

합리적인 설계 후보이다. 다만 1:1이 필요한지 데이터로 확인하고, dense target의 효과와 mask의 효과를 분리해야 한다. 엄격한 causal mask는 action이 자기 뒤의 tactile 예측을 읽는 경로를 막는다. Full attention과 transition block 구성을 함께 비교한다.

Q07Dense WAM은 성능·비용이 나빠지고 우리 모델은 괜찮다면 좋은 결과인가?

잘 통제한 비교라면 강한 근거가 된다. 하지만 기존 모델의 성능 저하가 필수는 아니다. 같은 계산 예산에서 더 높은 성능, 같은 성능에서 더 낮은 비용도 충분하다. Video까지 불필요하게 dense하게 만들거나 loss scale·batch size 차이로 baseline이 불리해지지 않게 한다.

Q08Gripper보다 dexterous에서 dense prediction의 이득이 크면 어떤가?

좋은 보조 결과이다. 각 embodiment의 dense–sparse 개선량을 비교해야 하며, task·sensor·기본 난이도 차이를 통제해야 한다. 초기에는 같은 hand에서 접촉 수·전환 빈도·하중 이동을 조절하는 것이 원인을 설명하기 쉽다.

Q09DUST가 ICML에 accept되었다면 WAM에 지나치게 매몰될 필요는 없지 않은가?

그렇다. 최종 포지셔닝은 VLA의 action generation 개선이다. 게재 사실이 연구 분류에 대한 공식 판정은 아니지만, 이 방향의 연구가 학술적으로 성립하는 사례다. 가장 직접적인 baseline은 같은 VLA, auxiliary prediction, DUST의 tactile 확장이다. WAM 직접 비교는 주장 범위에 맞춰 배치한다.

Q10Predicted–measured tactile 오차의 action gradient로 보정할 수 있는가?

Action-conditioned differentiable model을 통한 미래 결과 최적화는 가능하다. 그러나 이미 측정된 과거 tactile은 아직 실행하지 않은 미래 action으로 바꿀 수 없다. Residual로 현재 상태·belief를 갱신하고 미래 접촉 비용을 최적화하거나, 실행된 prefix를 고정한 posterior conditioning을 설계해야 한다.

작은 비교로 핵심 가설을 확인하고, 결과에 맞춰 확장한다

제안된 계획 아래 단계와 판단 기준은 앞으로 할 일이다. 실험을 수행했거나 특정 결과가 나왔다는 의미가 아니다.

P0

센서·action 시간축과 데이터 문제를 먼저 확정

장비, 실제 측정·제어 주기, 통신 지연, timestamp 정렬, force 좌표계·정규화, tactile history 길이를 정한다. Contact onset·release·force peak의 지속 시간을 측정한다.

Tt+1을 순간값으로 둘지, action 실행 구간의 평균·peak·접촉 상태를 함께 담을지 정한다. 측정되지 않은 고주파 정보를 interpolation으로 만들어 dense supervision으로 간주하지 않는다.

판단: Sparse sampling이 중요한 이벤트를 놓치는가? 그렇지 않다면 density 자체보다 representation·coupling에 초점을 조정한다.
P1

같은 VLA에서 predictive augmentation의 가치를 확인

현재 tactile/history를 받는 VLA, tactile auxiliary prediction, DUST 방식의 tactile 확장, dense dual stream을 비교한다. 처음부터 feedback controller까지 함께 바꾸지 않는다.

판단: Dense prediction이 예측 지표와 policy 성능 모두에 도움이 되는가? 예측만 좋아지면 action으로 전달되는 정보 경로를 재검토한다.
P2

Density · stream · mask 효과를 분리

동일한 backbone·tactile encoder를 유지하고 아래 2×3 비교를 수행한다. Mask의 이득은 dense full attention 대비로 판단한다.

판단: 제안 mask가 낫지 않으면 mask를 핵심 기여에서 제외한다. 실제로 검증된 dense modeling의 효과를 중심으로 정리한다.
P3

접촉 복잡도·일반화·비용으로 설명력을 높임

같은 hand에서 안정적인 접촉, 반복 regrasp, 손가락 간 하중 이동을 비교한다. 물체·마찰·강성·초기 자세를 분리해 hold-out 평가하고 latency와 메모리를 측정한다.

판단: 효과가 발생하는 조건을 설명할 수 있는가? WAM보다 효율적이라는 주장을 하려면 해당 조건의 직접 비교를 추가한다.
P4

필요할 때만 execution-time steering으로 확장

기본 prediction이 유효하고 action 변화에 대한 응답도 정확할 때, measured–predicted residual을 이용하는 후속 보정을 검토한다. Short-chunk replanning, reactive policy, TacPAC-style corrector를 비교 후보로 둔다.

후속 아이디어: Steering

Main idea의 효과를 확인한 뒤 확장할 별도 연구 축

원래 제안

실행 중 얻는 measured tactile과 미리 예측한 tactile의 차이를 계산하고, 그 차이의 action gradient를 guidance로 사용해 남은 action을 보정하는 구상이다. CFG·classifier guidance에서 영감을 얻었으나, 실제 목적함수와 gradient의 의미는 별도로 설계해야 한다.

과거 오차를 미래 action으로 직접 바꿀 수는 없다. 실행된 history를 고정했을 때 이미 측정된 Ts는 아직 실행하지 않은 action Afuture에 의해 달라지지 않는다. Joint model에서 그 방향의 수치 gradient가 생기더라도 곧바로 물리적으로 유효한 보정 방향이라고 해석할 수 없다.

ViTaL의 steering 원리

  1. 후보 생성: 기존 policy에서 여러 action 후보를 생성한다.
  2. Visual 선택: action-conditioned visuo-tactile world model의 예측 결과를 평가해 행동 방향을 선택한다.
  3. 부분 re-noise: 선택한 action을 anchor로 삼아 일부 noise를 추가한다.
  4. Tactile editing: 예측 tactile latent와 접촉 목표 text의 정합도를 reward로 삼아, 짧은 구간의 DDIM denoising에 gradient guidance를 적용한다.

ViTaL은 text-conditioned tactile reward를 사용하는 inference-time 최적화이다. 실행 중 매 sensor timestep의 predicted–measured error를 직접 줄이는 구성과 같지 않다.[9]

우리 sub-idea를 구체화하는 두 후보

후보 A

상태 추정 후 미래 접촉 비용 최적화

Measured–predicted residual로 현재 state/belief를 갱신한다. 갱신된 상태에서 action-conditioned tactile rollout을 만들고, 목표 접촉·force 제한·기존 계획과의 거리 등을 고려해 미래 action을 수정한다.

후보 B

관측된 prefix로 조건화해 suffix 재생성

실행된 action과 실제 tactile은 고정한다. 모델이 이 prefix에 조건화해 미실행 action과 tactile trajectory를 다시 생성하거나 보정하도록 학습한다. Noising·mask와 실제 적용 지연을 함께 설계한다.

비교 대상은 현재 tactile만 읽는 corrector, 예측 cache도 읽는 TacPAC-style corrector, 짧은 chunk 재계획이다. 동일한 sensor 접근·action 갱신 주기에서 prediction reference 또는 gradient가 주는 추가 이득을 확인한다. 이미 실행된 command와 correction 계산 중 실행될 command를 수정 대상으로 삼지 않는다.

Main idea의 학습 이득과 sub-idea의 execution-time 보정 이득은 각각 보고한다. 두 효과를 함께 바꾸면 원인을 분리하기 어렵다.
