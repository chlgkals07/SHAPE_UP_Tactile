SECTION 01최종 결정

실제 구매의 기본 선택은 XELA uSkin LEAP 통합형입니다. 센서 개발보다 촉각·고유감각 기반 조작 연구에 집중하려는 목적에 가장 잘 맞습니다. 단, 이는 통합 편의성과 연구 운영성을 반영한 구매 판단입니다. 사용자가 지정한 직접 LEAP 논문 근거를 우선하는 종합 순위에서는 PaXini가 1위입니다.

PaXini는 출판된 LEAP 구성과 현재 구매 가능한 모듈의 일치 여부가 확인되면 특히 좋은 선택입니다. GelSight Mini는 접촉 형상 연구용 3위로 유지하고, AnySkin은 빠른 저차원 입력 실험·교체 가능한 skin 연구의 우선 후보로 분리합니다. WowSkin은 AnySkin과 동일한 검증 수준으로 취급하지 않습니다.

두 보고서를 합치며 달라진 점

클로드 보고서가 추가한 PTLD, TaSA, Tac3D, MIDAS, TacO, FingerEye, DexSkin, LeapTac, RGB-S를 원문과 대조했습니다. 특히 PTLD는 XELA의 tactile/proprioceptive 연구 적합성을 강화합니다. 반대로 “광학식은 RL에 부적합”, “AnySkin/WowSkin은 전부 오픈소스”, “FSR baseline을 별도 구매해야 한다”는 일반화는 채택하지 않았습니다.

분류는 A-policy: 실물 LEAP 자율 학습, A-control: 실물 LEAP 촉각 제어, A-demo: 장착·원격조작 시연, B: 공식 LEAP 통합, Other: 다른 손/그리퍼, 미확인으로 구분합니다. A-demo는 A-policy와 같은 강도의 증거가 아닙니다.

SECTION 02LEAP 연구자들이 실제로 쓰는 것

문헌에는 두 경향이 있습니다. 하나는 접촉을 단순화해 sim-to-real을 용이하게 하는 접근이고, 다른 하나는 연속 촉각 신호의 표현과 융합을 학습하는 접근입니다. 이 표본만으로 어떤 센서가 전체 LEAP 문헌에서 “가장 흔하다”고 단정하지 않습니다.

해석할 때 주의할 세 가지

  • PaXini의 초기 두 대표 논문은 같은 연구 계열입니다. 독립적인 검증의 폭과 논문 수를 구분합니다. 더 최근의 cluttered grasping 연구도 있지만 아직 새 preprint입니다.
  • XELA의 LEAP 근거는 공식 통합입니다. 이 조사에서 직접 LEAP 정책 논문을 검증하지 못했습니다. “세계 최초 논문을 낼 수 있다”는 보장은 하지 않습니다.
  • 표준 LEAP, 3-finger redesign, LEAP v2는 구분해야 합니다. 논문이 revision을 명시하지 않으면 외형만으로 v1이라고 확정하지 않습니다.

SECTION 07정책 입력과 연구 설계

보존해야 할 관측

oₜ = [qₜ, q̇ₜ, tactileₜ] + 시간 이력
센서 계열 native / 관측 형태 encoder 선택 해석상 주의
Force array N×3 + taxel pose MLP baseline, graph, point transformer force는 calibration을 거친 추정량
Magnetic skin Nₘ×3 magnetic readings temporal MLP/CNN, transformer raw 자기장 값은 N 단위 힘이 아님
Pressure map H×W CNN, sparse spatial encoder normal 반응을 shear로 오인하지 않기
Optical tactile H×W×C CNN/ViT, Sparsh, geometry extractor depth·변형·force는 서로 다른 추론 목표
Binary contact N MLP/RNN sim-to-real에는 간편하지만 정보를 버림

Graph/point 표현에서는 관절 상태로 계산한 taxel 위치와 센서 좌표계를 함께 사용합니다. 시간 이력은 loading, relaxation, slip-related 변화를 보존하는 데 유리합니다. 평균·최댓값·미분만으로 incipient slip 정보를 반드시 보존한다고 보장할 수는 없습니다.

권고하는 두 연구 경로

경로 A — 직접 실물 학습. PaXini/XELA raw와 force를 기록하고, 공간·시간 encoder를 policy에 연결합니다. 작은 task 세트에서 representation과 tactile ablation을 먼저 검증합니다.

경로 B — sim-to-real + 실물 tactile distillation. 시뮬레이션에서는 object pose 등 privileged 정보를 활용하고, 실물에서 촉각과 paired state를 수집해 deployable encoder를 학습합니다. PTLD가 이 접근의 구체적 선례입니다. 카메라를 학습 시 정답 생성에 사용해도 배포 policy를 촉각·고유감각 중심으로 만들 수 있습니다.

Binary contact는 유용한 baseline이지 의무적인 최종 입력이 아닙니다. 같은 풍부한 센서의 출력을 thresholding하면 별도 FSR을 사지 않고도 정보량 ablation을 할 수 있습니다. 물리적으로 FSR 자체를 비교하는 연구라면 별도 장착이 필요합니다.

첫 논문에 권하는 비교

  1. q/q̇만 사용 → binary contact 추가 → normal 추가 → full tri-axis 추가.
  2. 동일 센서·controller에서 flattened MLP와 spatial/temporal encoder 비교.
  3. fingertip-only와 tip+pad / palm coverage 비교.
  4. 처음 잡은 뒤 external vision을 끄는 조건과 계속 사용하는 조건 비교.
  5. 물체·마찰·날짜·교체 skin을 바꿔 generalization 평가.

센서의 두께·마찰·순응도는 로봇 동역학의 일부가 됩니다. CAD만 수정하지 말고 collision geometry, taxel transform, 필요하면 URDF/MJCF도 함께 갱신합니다. LEAP v2에는 기존 mount가 그대로 맞는다고 가정하지 않습니다.

통신과 compute

Magnetic/force array는 데이터 양이 작지만 encoder까지 항상 CPU만으로 충분하다는 보장은 없습니다. 광학식은 여러 스트림의 USB 대역폭·전력·host controller 분배를 검증해야 합니다. XELA의 손 전체 연결은 제조사 문서상 CAN bus cable 두 개이며 “물리적 전선 두 가닥만 있으면 된다”는 뜻으로 바꾸지 않습니다.

입고 후 수락 시험 — 제안

  • 무접촉 동작: 손가락을 전 가동 범위로 움직이며 drift와 모터/인접 skin 간섭 확인.
  • 반복 접촉: 동일 indenter·하중·접촉 위치에서 반복성, hysteresis, creep 확인.
  • 동기화: joint/tactile timestamp, 지연 분포, dropout, 장시간 기록 안정성 확인.
  • 기구: 극단 joint pose의 케이블 당김·충돌·손상 위험 확인.
  • 교체: skin 또는 센서 교체 후 calibration·policy 성능 재평가.

빠른 시작 순서

XELA는 factory integration이 실제 납기에 맞으면 가장 적은 기구 작업으로 시작할 수 있습니다. PaXini는 연구 구성 일치가 확인될 때 재현 경로가 빠릅니다. Mini는 공개 mount를 참고한 두 손가락 geometry 실험에 적합합니다. AnySkin/WowSkin은 조립된 제품과 LEAP adapter가 실제로 확보된 경우에만 빠른 경로입니다. 특정 기간 내 완성을 보장하지 않습니다.

1 — XELA uSkin: 전손 연구 인프라 1순위

현재 기본 구매안은 XELA입니다. 제조사가 공개한 LEAP 전용 구성은 fingertip 120, phalange 176, palm 72를 합한 368 sensing points에서 3축 접촉과 온도를 측정하며, 전체 1,472 measurements와 최대 220 Hz를 명시합니다. 두 CAN bus cable, Linux/ROS/ROS2, Python/C++ 경로도 공개되어 있어 전손 force·shear를 정책에 연결하는 연구 인프라로 가장 완성도가 높습니다. 다만 공식 페이지는 uSkin이 설치된 LEAP 주문을 중심으로 설명하므로, 사용자가 보유한 LEAP에 센서만 retrofit할 수 있는지와 그때의 BOM·보증을 서면으로 확인해야 합니다. retrofit이 제공되지 않으면 PaXini가 1순위로 올라갑니다.

2 — PaXini PX-6AX: 직접 LEAP 정책 근거 1순위

강점은 sensor pose와 tri-axis force를 실제 LEAP learning에 사용했다는 것입니다. AdapTac은 각 손가락에 fingertip 1개와 finger pad 1개, 총 8개 3×5 tri-axis array를 장착해 force-guided fusion과 future-force prediction을 학습했습니다. 이는 본 프로젝트와 가장 가까운 직접 논문 근거입니다. 그러나 논문이 정확한 세대·SKU를 공개하지 않아 현재 국내 판매 GEN3와 기구·전기적으로 동일하다고 볼 수 없습니다. 현재 모듈, controller, cable, power, Linux SDK와 논문 구성의 대응표를 받아야 일괄 발주가 안전합니다.

AdapTac · PaXini GEN3

3 — GelSight Mini: 형상 기반 조작의 보조 주력

실제 LEAP 제어 논문, 상용 구매, 공개 mount와 코드를 모두 연결할 수 있어 3위로 유지합니다. IROS 2024 연구는 엄지와 검지에 Mini 두 개를 장착하고 depth/contact geometry로 케이블의 3D 상태를 추정했습니다. 접촉 형상·표현학습에는 세 후보 중 가장 강하지만, 4개 카메라의 USB 대역폭·전원·배선, 25 FPS, 커진 fingertip envelope와 직접 보정된 3축 힘이 아니라는 점 때문에 전손 force-aware policy의 기본안으로는 3위입니다. 세 후보를 모두 사라는 뜻은 아닙니다. 첫 논문이 force-aware stabilization이면 XELA/PaXini 하나에 집중하고, 접촉 geometry가 질문의 중심일 때 Mini를 도입합니다.

IROS 2024 논문 · LEAP mount와 코드 · GelSight Mini

AnySkin이 종합 3위가 아닌 이유

교체 가능한 raw magnetic pipeline으로는 매력적입니다. 하지만 직접 LEAP 정책 성능과 공간 분포 정보의 근거가 제한됩니다. WowSkin의 편의성은 AnySkin 논문의 성능 보장을 대신하지 못합니다. 따라서 prototype / skin-transfer 트랙의 1순위 후보로 두는 편이 더 정확합니다.

Tac3D는 실제 LEAP force-feedback control이 있어 중요한 도전자입니다. 다만 현재 구매·지원·내구성 조건과 활용 가능한 연구 구현을 충분히 확정하지 못해 Mini보다 위에 두지 않았습니다.

SECTION 11예산 제한이 없을 때

주력: XELA LEAP 통합형 + raw access + 개별 calibration 선택 검토 + 교체품.

대안: 정확한 연구 구성으로 공급 가능한 PaXini 패키지.

보조: 필요한 fingertip에 Mini. DIGIT360은 별도 multimodal platform으로 관심 후보이지만 현행 LEAP 장착과 조달을 확인하기 전에는 주력 shortlist를 대체하지 않습니다.

개별 calibration을 추가하더라도 raw를 포기하지 않습니다. PTLD가 관찰한 processed force의 lag는 “비싼 calibration을 쓰면 모든 문제가 해결된다”는 결론을 막는 근거입니다. 안정적인 운영·지원·raw export·시간 동기화에 예산을 우선 배정하는 것이 좋습니다.
