# 조사 HTML 스냅샷

브라우저에서 [`index.html`](index.html)을 먼저 연다. 기존의 전체 HTML 보고서는 [`hardware-survey.html`](hardware-survey.html)에 보존했다.

이 HTML은 촉각센서 후보를 넓게 탐색한 **AI-assisted 조사 스냅샷**이다. 팀이 모든 논문을 정독하고 검증한 literature review가 아니며, 현재와 다른 과거 순위와 구매 판단도 포함한다.

현재 하드웨어 결정과 구매안은 상위 폴더의 [`README.md`](../README.md)와 [`paxini-integration.md`](../paxini-integration.md)를 기준으로 한다. 논문 내용을 인용하기 전에는 반드시 원문을 확인한다.
